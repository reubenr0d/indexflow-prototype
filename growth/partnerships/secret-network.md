# Secret Network

## Why this partnership exists

Secret Network's confidential computing primitives map directly onto a long-running design question for basket vaults: how does a curator express a proprietary asset weighting without leaking the weighting to copy-traders the moment it lands on-chain? The long-term path is a *Private Curators* sub-track where the basket's NAV stays publicly verifiable through the existing oracle and vault accounting stack, but the underlying asset weights are held inside a Secret contract and only the curator (and authorised viewers) can read them. Within IndexFlow's Week 3 confidential-infra trinity, Secret Network covers the *State* leg — paired with iExec for *Compute* and Nox for *Signing*.
